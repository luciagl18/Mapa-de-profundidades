# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),

## [0.1.0] - 2026-01-14

### Added
- Initial project structure
- DataLoader module for loading order book data from CSV and JSON
- DepthAnalyzer module for analyzing order book depth
- DepthVisualizer module for creating visualizations
- Main CLI application for running analyses
- Unit tests for all modules
- Example data files
- Comprehensive documentation
- Configuration files and examples
