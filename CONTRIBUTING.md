# Guía de Contribución

## Bienvenido

Gracias por considerar contribuir a Mapa de Profundidades. Este documento proporciona guías para contribuir al proyecto.

## Cómo Contribuir

### Reportar Bugs

- Usa el issue tracker de GitHub
- Describe el bug en detalle
- Incluye pasos para reproducir
- Proporciona información del sistema y versiones

### Sugerir Mejoras

- Abre un issue con la etiqueta "enhancement"
- Describe la funcionalidad propuesta
- Explica por qué sería útil

### Pull Requests

1. Fork el repositorio
2. Crea una rama desde `main`:
   ```bash
   git checkout -b feature/mi-nueva-caracteristica
   ```
3. Realiza tus cambios
4. Añade tests si es necesario
5. Asegúrate de que todos los tests pasen
6. Commit con mensajes descriptivos
7. Push a tu fork
8. Abre un Pull Request

## Estándares de Código

### Python

- Sigue PEP 8
- Usa type hints cuando sea apropiado
- Documenta funciones y clases con docstrings
- Mantén las funciones pequeñas y enfocadas

### Tests

- Escribe tests para nuevas funcionalidades
- Mantén la cobertura de tests alta
- Usa nombres descriptivos para los tests

### Documentación

- Actualiza README.md si es necesario
- Documenta APIs públicas
- Incluye ejemplos de uso

## Proceso de Revisión

- Un mantenedor revisará tu PR
- Pueden solicitar cambios
- Una vez aprobado, tu código será merged

## Código de Conducta

- Sé respetuoso y constructivo
- Acepta críticas constructivas
- Enfócate en lo mejor para el proyecto

## Preguntas

Si tienes preguntas, no dudes en:
- Abrir un issue
- Contactar a los mantenedores

¡Gracias por contribuir!
